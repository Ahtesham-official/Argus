# 🛡️ Argus

> AI-powered health insurance claim verification and risk assessment platform.

---

## 🚀 About

Argus helps streamline insurance claim processing by analyzing:

- 📄 Medical & claim documents
- 🧠 AI-generated insights
- 🔍 Claim inconsistencies
- ⚠️ Potential fraud indicators
- 🏥 Healthcare data

---

## ✨ Core Features

- 📑 AI-powered document analysis
- 🔎 Claim verification
- 🧠 Intelligent risk assessment
- 🏥 ABHA / ABDM integration
- 🔗 NHCX interoperability
- 📊 Claim review dashboard

---

## 🏗️ Tech Stack

- ⚛️ Frontend: React
- 🟢 Server: Node.js + Express
- 🗄️ Database: MongoDB
- 🤖 AI: Qwen + Mistral
